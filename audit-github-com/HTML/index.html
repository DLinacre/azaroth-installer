What it does for you

⚡ Full auto install

Approve the UAC prompt and click once. The wizard picks the best drive, downloads what's missing, configures everything, and verifies the server boots before handing over.

🤖 PlayerBots, ready to play

Random bots fill the world; lfg instantly fills a raid tank/healer/DPS. Summon any class, run your alts as bots, configure population and guilds.

🧠 Smart detection

Probes CPU, RAM, GPU and every drive; finds your existing WoW 3.3.5a client; detects any repack layout; reuses any existing MySQL/MariaDB — and never destroys your characters on re-runs.

🛡 Safety built in

Zip-slip protection, idempotent installs, repair mode, a live log with automatic diagnostics, and localhost-by-default networking.

🧩 Module picker

Toggle every module DLL your repack ships (transmog, AH bot, guild houses…), add extra modules by URL, and install the GM Genie add-on in one click.

🔧 Make it yours

Realm name, XP/Honor/Gold rates, level cap, bot population, GM credentials — all in the wizard, or pre-configured via config.json.

Frequently asked questions

Is this legal?

The installer is open source (MIT) and does not redistribute Blizzard files — it reuses the 3.3.5a client you own. Running a private server can violate Blizzard's EULA/ToU; it's intended for private, non-commercial, educational use at your own risk.

Why does SmartScreen warn me?

The community build isn't code-signed (yet). Click “More info → Run anyway”. Verify the SHA-256 checksum on the release page. Signed builds are on the roadmap.

Can I play with friends?

Yes — enable LAN play, set the auth/realm address to the server PC's LAN IP, and the installer opens the firewall for the local subnet. Don't expose the server to the internet without changing credentials.

Where do I get a “prebuilt repack”?

The wizard is repack-agnostic and accepts any prebuilt Windows AzerothCore 3.3.5a zip. Host your own, or use a community repack you trust. A direct HTTPS link can be set in config.json.
